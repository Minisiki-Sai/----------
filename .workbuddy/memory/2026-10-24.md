## 修复 tools/dev_run.ps1 的清理崩溃（用户实测报错）
- 症状：`taskkill.exe : ERROR: The process with PID 37576 ... could not be terminated` 之后启动器直接中断，dev 模式根本起不来。
- 原因1：脚本顶部 `$ErrorActionPreference='Stop'`，而清理用的是 `& taskkill.exe ... 2>&1 | Out-Null`。PS 5.1 会把原生命令写往
  stderr 的内容包成终止性 NativeCommandError。改法：只用 `2>$null` 丢弃 stderr，并局部降级 EAP，绝不合并进成功流。
- 原因2（真实根因）：残留的 `dragon-nest-simulator-v420.exe`(PID 29240) 以**管理员权限**运行，它拉起的 `DragonNestEngine.exe`(38968)
  正监听 48710。未提权的 shell 对该进程树一律「拒绝访问」，taskkill /T /F 与 Stop-Process 都无效。
- 改动：
  1. 新增 `Stop-ProcessTreeById` / `Test-ProcessAlive`：taskkill 失败降级 Stop-Process，任何路径都不抛异常。
  2. `Stop-NamedProcess` 改为按父子深度倒序结束（先子后父，避免父先死导致子变孤儿），残留时打印「管理员权限」提示。
  3. `Stop-PortListener` 改为返回是否释放；新增 `Assert-PortFree`：端口没释放就打印两种可执行的处理办法并 `exit 1`，不再抛栈。
  4. preflight 清理后立即 `Assert-PortFree` 校验 48710 / 1420。README 开发段补了这条排查说明。
- 验证：`Parser::ParseFile` PARSE OK；实跑输出干净、exitcode=1、无 native error 栈（29240 仍提权运行，所以必然走该分支）。

### 关键结论：进本后才开统计，缺的是「Boss 实体定义包」
- 现场数据（新代码、running、elapsed≈53s）：

## 梦魇海龙三个实测问题（P2 冰眼/龙息要放一次、终局残留已好、换边仍提示）

抓包：`C:/Users/wuyaoxiang/Desktop/抓包文件/capture_20261024_梦魇海龙.dpscap`（2247s 全流程）、
`capture_20261025_梦魇海龙2.dpscap`（1257s，含 P2 到 1257 截断）、`..._梦魇海龙3.dpscap`（347s）。

**根因（数据实证，不是猜）**
1. **「冰眼/龙息要放过一次才出来」= 被分边过滤吞了第一次**。
   `lastAttackTargets` 是永久表，本机最后目标一直停在 725s 就已经飞走的 P1 海龙
   0x2C@4237003 → identity 的 tier0 把 `current` 判成 4237003 → 它又和 P2 空中海龙
   4237034 组成「两组」→ hint=(4237003,[4237034]) → 1010.9s 第一次冰眼、1041.8s 第一次
   龙息整行被 `filterCurrentGroupRows` 丢掉；1026s 后 hint 消失，第二次才开始正常。
2. **「终局仍显示天启/狮蝎已好」= 天启没有死亡行**。血量包最后一条是
   156428/900000000 = 0.017%（客户端 Boss 死亡即停更），`VoiceSignalFeed.health`
   只在 `current_hp <= 0` 才发死亡行 → `SeaReminderClock` 永远不 `dead` → pending 里的
   「六芒星/旋转/召唤触手…已好」永久保留（`countdowns()` 在 cooldown 模式下全量返回）。
3. **「换边后对侧还在提示」= 倒计时条目没随分组清理**。前端只对**输入行**做分组过滤
   (`filterVoiceRows`)，已经 armed 的 pending 会继续倒数并播「xx 已好」。

**改动**
- `aggregator`：新增 `recentAttackTargets`（15s 时效，`_ATTACK_TARGET_TTL_MS`），

  统一取时效表，identity tier0 / 分边分组 / 分边对侧 / 副本推断全部改用它。
  队伍血条 `party_boss_health` **保持永久表**（整队跑位 15 秒不该整排消失）。
- `split_peer_boss_templates`：加两道闸门
  ① 场上必须真有**两组人各打一只**（`_current_target_groups` 长度 ≥2），
