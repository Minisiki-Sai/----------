## 修复开发启动器找不到 pnpm（run_v420_dev.ps1）

现象：双击 `启动V4.68开发版.bat` 报 `pnpm was not found`。
根因：唯一的 `pnpm.CMD` 在 `%USERPROFILE%\.workbuddy\binaries\node\versions\22.22.2-6\`，该目录只在 WorkBuddy 的 bash PATH 里，未进 Windows PATH，因此 bash 能跑 `pnpm -v`、双击 bat 起的 PowerShell `Get-Command pnpm.cmd` 却为空。`%ProgramFiles%\nodejs` 只有 corepack 没有 pnpm；脚本里的 codex fallback 路径也不存在。
修复：在 `run_v420_dev.ps1` 新增 `Resolve-PnpmPath`，按 PATH → codex fallback → `%APPDATA%\npm` → `%ProgramFiles%\nodejs` → `~/.workbuddy/binaries/node/versions/*/pnpm.CMD`（按修改时间取最新）逐级探测，并让报错信息列出已检查位置。
验证：把 PATH 中 workbuddy 相关目录剔除后跑 `run_v468_dev.ps1`，仍能起 48710 健康检查和 1420 Vite（HTTP 200）。
覆盖范围：`run_v440/v467/v468_dev.ps1` 等都委托到 `run_v420_dev.ps1`，一处修改对 V4.40~V4.88 生效；V4.10 走 `py.exe` 不受影响。
