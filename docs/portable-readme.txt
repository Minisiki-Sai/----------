DN倒计时工具 V4.88（免安装绿色版）
==================================

解压后双击 dn-countdown.exe 或 Start-Portable.bat 即可运行，不写注册表、
不建快捷方式，删除整个文件夹即卸载。

一、只做两件事
--------------
1. 增益 / 减益倒计时悬浮窗（浅蓝磨砂胶囊条）
2. Boss 技能倒计时悬浮窗（暖橙磨砂胶囊条）

没有配装、配队、评分、排行、历史记录、导出、诊断上传等任何其它功能。

二、第一次使用
--------------
1. 双击 dn-countdown.exe。
2. 抓包依赖 Npcap。已装过 Npcap 的机器可直接用；没有时：
   - 右侧「Ncap 路径」→「检测」，按提示安装 Npcap（third_party\npcap\npcap-1.88.exe，
     安装时勾选「WinPcap API 兼容模式」，需要管理员权限）。
   - 也可点「选择 DLL」「选择目录」手动指定 wpcap.dll 或安装目录，保存后立即生效。
   - 「测试连接」会真正加载 wpcap.dll 并枚举接口，区分「找不到 Npcap」「权限不足」
     「接口为空」三类错误。
3. 进入游戏后点「开始统计」，两条悬浮窗随抓包自动刷新；「停止」结束。

三、两个采集开关
----------------
关闭「增益 / 减益」或「Boss 技能」后，后台对应通道立即停止解析（事件不进入聚合器、
不更新悬浮窗），重新打开即恢复；抓包线程与另一通道不受影响。

四、数据位置
------------
- Ncap 路径：程序目录 data\npcap.json（随包迁移，换引擎不丢）
- 界面设置 / 悬浮窗位置：%LOCALAPPDATA%\com.gcg.dragon-nest-simulator.v420（WebView2 本地存储）
- 抓包临时文件：%TEMP%\DragonNestACT\working\*.dpscap，停止统计时清理

五、排错
--------
1. 双击没反应：确认 runtime\engines 下引擎完整、runtime\active-engine.json 存在。
2. 提示「未找到 Npcap」：见第二节，装好 Npcap 后点「检测」。
3. 提示「权限不足」：以管理员身份运行一次，或重装 Npcap 时取消「仅管理员访问」。
4. 提示「没有可用抓包接口」：确认网卡已启用、未被防火墙/代理拦截。
5. 悬浮窗不动：确认「开始统计」处于抓包中，且对应采集开关是打开状态。
